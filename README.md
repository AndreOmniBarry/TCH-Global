# TCH Global

Website for TCH Global, a church reaching every nation with the Gospel.

## Structure

- `index.html` - Home page
- `about.html` - Mission, values, and leadership
- `sermons.html` - Sermon library
- `events.html` - Upcoming events
- `give.html` - Online giving
- `contact.html` - Contact form and location details
- `css/styles.css` - Site styling
- `js/main.js` - Navigation and giving form interactions
- `images/` - Site imagery (placeholders to be replaced)

## Development

This is a static site — open any HTML file in a browser, or serve the
directory with any static file server, e.g.:

```
npx serve .
```
